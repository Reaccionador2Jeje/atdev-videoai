# Contributing

Thanks for helping improve AtDev VideoAI!

## Principles
- Keep the core free of credits and artificial paywalls.
- Prefer open formats and tools.
- Keep external services optional.
- Explain hardware requirements and third-party quotas honestly.
- Never commit API keys, tokens, private media, or personal data.

## Changes
1. Open an issue describing the problem or proposed feature.
2. Keep pull requests focused and document how to test them.
3. Include screenshots or sample project files for visual changes when useful.
4. Update documentation when behavior or setup changes.

The project is in its foundation stage. Read the README and architecture document before proposing major dependencies.
